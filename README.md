# 🔹 ReqIntel AI

### AI-Powered Requirement Intelligence Platform

ReqIntel AI is an AI-powered document intelligence platform that enables users to upload PDF documents and interact with them using natural language. By leveraging Retrieval-Augmented Generation (RAG), semantic search, and vector embeddings, it delivers accurate, context-aware answers grounded in the uploaded document.

### ✨ Features

- 📄 Upload and analyze PDF documents
- 🤖 Natural Language AI Chat
- 📑 Automatic PDF Text Extraction
- ✂️ Intelligent Document Chunking
- 🧠 OpenAI Embedding Generation
- 🔍 Semantic Vector Search
- 📚 Retrieval-Augmented Generation (RAG)
- 💬 Context-Aware AI Responses
- ⚡ Fast Document Indexing
- 🗄️ PostgreSQL + pgvector Vector Database
- ☁️ Cloud Deployment (Render, Vercel & Neon)
- 🔐 RESTful ASP.NET Core APIs
